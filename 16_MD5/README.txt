MD5 Hashing using Python Sockets

1. Open two terminals at the CNS_Lab_Socket_Programs root folder.
2. Terminal 1: py 16_MD5\server.py
3. Terminal 2: py 16_MD5\client.py
4. Enter a message in the client. The server prints the MD5 digest.

MD5 produces a 128-bit (32 hexadecimal-character) digest.
Security note: MD5 is cryptographically broken and must not be used for security-sensitive integrity or password storage. This program is for lab learning only.

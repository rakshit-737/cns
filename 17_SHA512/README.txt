SHA-512 Hashing using Python Sockets

1. Open two terminals at the CNS_Lab_Socket_Programs root folder.
2. Terminal 1: py 17_SHA512\server.py
3. Terminal 2: py 17_SHA512\client.py
4. Enter a message in the client. The server prints the SHA-512 digest.

SHA-512 produces a 512-bit (128 hexadecimal-character) digest.
SHA-512 is a hash function, not encryption: the original message cannot be recovered from the digest.
